# Skills (the commons catalog)

The shared, portable skill cores live here, one directory per skill, each with a
`SKILL.md` plus optional siblings / `references/` / `assets/`. See
[FORMAT.md](../../FORMAT.md) for the format and the portable-core rules.

This catalog is **empty by design** at the skeleton stage. Skills are migrated in
from the originating repositories in later phases, starting with a single pilot
(`security-review`) to prove the extract -> vendor -> pin -> drift -> link-check
pipeline before the bulk.

When a skill is added, append a row here recording its name, trigger phrasing,
and any disambiguation against a competing skill.
