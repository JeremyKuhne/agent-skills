# Agent personas

Portable agent personas (`*.agent.md`) shared across the consuming repositories -
for example a generic, read-only code reviewer that cites the repo's own
instructions and skills rather than restating rules.

This directory is **a placeholder at the skeleton stage**. Personas are added
alongside the skills they pair with. A persona shared here must be portable: it
references owning skills/instructions by role, not by a specific repo's paths, so
each consuming repo's overlay can point it at the right local files.
